# MedTrust — полнота и точность формируемых ответов

- Расширены инструкции генерации: сохранять клинические пороги, диапазоны, популяцию и условия применимости; не превращать отдельный симптом в самостоятельный критерий диагноза.
- Добавлены динамические требования полноты для диагностических и лечебных вопросов. Для диагностики проверяются признаки, симптомы, длительность/частота, подтипы, анамнез/дневник и тревожные признаки — только в пределах того, что подтверждают переданные источники.
- Добавлен bounded second-pass review: модель сверяет черновик с тем же набором источников, исправляет повторы, устраняет чрезмерно общие формулировки и добавляет пропущенные подтверждённые сведения.
- Результат второго прохода принимается только при наличии допустимых цитат. При сбое или недопустимых цитатах остаётся предыдущий проверенный ответ. API возвращает `answer_reviewed`.
- Добавлены unit-тесты для диагностической полноты, ограничений на медицинские назначения и второго прохода.
- Добавлен `docs/MEDICAL_QA_EVALUATION.md` с определениями метрик и планом клинической оценки.

## Важное ограничение

Версия v13 улучшает процесс формирования ответа, но не подтверждает, что precision, recall и accuracy уже выше 0.95. Для этого нужен репрезентативный размеченный набор медицинских запросов, независимая клиническая оценка ответов и измерение метрик на отложенной выборке. Второй проход той же языковой модели не является независимой проверкой медицинской истинности.
