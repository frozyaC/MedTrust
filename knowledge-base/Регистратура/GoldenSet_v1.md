# Golden set v1 — Регистратура

**Состав:** 49 вопросов — 6 категорий (по 8 вопросов, в «Сложные — частичный ответ» 9). Сквозная нумерация Q01–Q49 по порядку категорий.
**Источник базы знаний:** `knowledge-base/Регистратура` (файлы `test-questions.md`, `test-questions-answers.md`, `test_questions_v2` не использовались).
**Формат вопросов:** так, как регистратор вводит их в систему — коротко, тезисами, без вопросительных знаков.
**Один вопрос = одна тема.** Вопросы про парковку, подготовку к приёму и стоимость в одном запросе не объединялись.

## Категории

| Категория | Что означает |
|---|---|
| Простой | Ответ целиком лежит в одном файле базы |
| Сложный | Для одного ответа нужно собрать информацию из нескольких файлов |
| Полный ответ | В базе есть все факты, чтобы ответить |
| Частичный ответ | Часть фактов есть, часть отсутствует или противоречит друг другу |
| Нет ответа | Ответа нет ни в одном файле |
