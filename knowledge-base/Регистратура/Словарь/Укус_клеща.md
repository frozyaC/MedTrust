
# Регламент записи при укусе клеща

**Помощь пациентам при укусе клеща в нашей клинике оказывается приоритетно в инфекционном отделении:** 

**Бокс 4  ДЕТСКОГО ИНФЕКЦИОННОГО ОТДЕЛЕНИЯ – дневное время**

**Бокс 3  ДЕТСКОГО ИНФЕКЦИОННОГО ОТДЕЛЕНИЯ – круглосуточно.**

==**Все пациенты заходят через отдельный вход с улицы по адресу Садовая 15, корпус 2.**== 

==**Помощь оказывается и ВЗРОСЛЫМ и ДЕТЯМ.**== 

==**Помощь оказывается КРУГЛОСУТОЧНО.**== 

==**Если пациенты позвонили – по предварительной записи, услуга доступна в расписании в Медиалоге в Модели**== 

==**«УКУС КЛЕЩА», модель есть и во взрослой и в детской.**== 

**Вносить пациентов при укусе клеща  нужно будет в расписание бокс 4 :**

**Бокс работает круглосуточно!**

|   |   |
|---|---|
|Д9919402|Прием врача в неотложном порядке для пациентов при укусе клеща|

**Входит осмотр врача, удаление клеща, расчет иммуноглобулина.** 

При необходимости **поставят иммуноглобулин:** расчет дозы 1 мл на 10 кг массы тела  (прим. вес 65 кг - ставят 7 мл иммуноглобулина)

|   |   |
|---|---|
|В9921996|Введение противоклещевого иммуноглобулина (титр 1:320, Россия) (1 мл.)|

Отправят [клеща на исследование](https://wiki.example.com/page-20)

|   |   |
|---|---|
|12355|Исследование клеща (боррелиоз, клещевой энцефалит)|
|12356|Исследование клеща (боррелиоз, клещевой энцефалит, анаплазмоз, эрлихиоз)|

При получении положительного результата необходима консультация [инфекциониста, невролога, терапевта](https://wiki.example.com/page-17)

> ПРИ ОСТРОМ СОСТОЯНИИ (температура, боли тд) в **«Центр клещевых инфекций» 12 ГКБ.** Важно в течении первых 72 часов начать пить антибиотики, не дожидаясь результатов анализа клеща (выдают бесплатно в муниципальных клиниках).
