# Правила записи

Дата последнего редактирования: 10.11.2026

Каналы записи на приём в клинику «КардиоЛайн». Записаться можно разными способами, чтобы пациентам было удобно.

По телефону. Телефон контакт-центра: +7 (495) 000-00-00, добавочный 1. Контакт-центр принимает звонки в часы работы клиники.

Через сайт. Официальный сайт клиники, раздел «Запись онлайн». Доступна круглосуточно.

На стойке регистратуры. В часы работы клиники. Подходит для пациентов, которые уже находятся в клинике.

Запись третьего лица. Возможна только при наличии согласия пациента. Для записи необходимы: фамилия, имя, отчество, дата рождения, контактный телефон, желаемая услуга и удобное время.

Дополнительные условия. Для некоторых исследований (нагрузочные тесты, Холтер) требуется предварительная консультация врача. Наличие свободного слота подтверждается только после внесения записи в систему клиники.

Подтверждение. Пациент получает SMS-подтверждение записи. За 24 часа до приёма приходит напоминание.
