# Персональные данные

Дата последнего редактирования: 10.11.2026

Правила обработки персональных данных пациентов в клинике «КардиоЛайн». Соблюдение правил защищает пациентов и клинику от правовых рисков.

Принцип минимизации. Обрабатываются только данные, необходимые для записи на приём и оказания медицинских услуг.

Конфиденциальность. Персональные данные не сообщаются третьим лицам без письменного согласия пациента. Передача результатов родственникам — только по письменному согласию.

Идентификация по телефону. Личность пациента подтверждается фамилией, именем и датой рождения. Номер записи, результаты исследований и сведения о диагнозе не передаются лицам, не подтвердившим личность.

Хранение. Данные хранятся в защищённой информационной системе с ограниченным доступом сотрудников.

Законодательство. Клиника соблюдает требования Федерального закона № 152-ФЗ «О персональных данных».

Инциденты. Нарушения фиксируются в журнале инцидентов и рассматриваются администрацией клиники. По результатам принимаются меры по предотвращению повторения.
