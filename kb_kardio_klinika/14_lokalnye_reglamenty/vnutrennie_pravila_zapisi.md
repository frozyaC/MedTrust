# Внутренние правила записи

Дата последнего редактирования: 10.11.2026

Внутренние правила бронирования слотов в клинике «КардиоЛайн». Правила помогают избежать двойных записей и обеспечить корректную загрузку врачей.

Один пациент — один слот на одну услугу. Не допускается резервировать несколько слотов на одно и то же время без необходимости.

Предварительная бронь. Без подтверждения действует 30 минут, после чего автоматически снимается.

Минимальная длительность слота. Для консультации — 30 минут.

Нагрузочные тесты. Резервируется 60 минут с учётом подготовки и восстановления.

Двойная запись. Допускается только с разрешения старшего администратора. При двойной записи пациенты обзваниваются и предупреждаются.

Запись на исследования без консультации врача. Допускается только при наличии направления.

Отмена. При отмене приёма слот сразу становится доступен для других пациентов. Это важно для сокращения очереди.
